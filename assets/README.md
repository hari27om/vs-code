# assets/

Empty by design. See Section 40 (3D Asset Rules) and Section 41
(Spider-Man IP Rule) before adding anything here:

- Store the original authored asset separately from runtime-optimized
  exports; the runtime build should only ship what it needs.
- A Spider-Man asset may be used for private/local prototyping subject
  to that asset's own license. It must NOT be assumed usable for public
  release/Marketplace distribution — Marvel's character, logo, suit
  artwork, and sounds are not automatically licensed for that.
- The character controller (Section 42) must stay asset-agnostic so the
  model can be swapped without touching the physics engine.
